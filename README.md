# cible-lumineuse-neopixel
Système de cible lumineuse réactive à l'impact par Taka Tech Lab. Code Arduino Open Source gérant un anneau NeoPixel (WS2812B) via une machine à états asynchrone. Signal stroboscopique haute visibilité pour le tir sportif. Schéma de câblage et gestion dynamique de la fréquence inclus. (293 caractères)
